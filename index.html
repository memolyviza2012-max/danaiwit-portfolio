    ขั้นตอนทำงานHow I work

    ตรวจงานได้เป็นช่วง ตั้งแต่คุยบรีฟจนถึงรับไฟล์ที่ทีมใช้ต่อได้Review the work at each stage, from the first brief to the files your team can use.

    1. กำหนดขอบเขตDefine the scope

      คุยกันเรื่องการใช้งาน ภาพอ้างอิง ขนาด จุดที่ต้องแยกชิ้น และรูปแบบไฟล์ที่ทีมปลายทางต้องใช้Agree on the use case, references, scale, which parts move or need to be separate, and required file formats.

    2. ตรวจโมเดลร่างReview the blockout

      ส่งภาพมุมหลักเพื่อตรวจสัดส่วนและตำแหน่งชิ้นส่วนก่อนลงรายละเอียด พร้อมระบุจุดที่ต้องการความเห็นReview key views, proportions, and part placement before detailing. Flag decisions that need your input.

    3. ลงรายละเอียดและวัสดุModel and texture

      เก็บรายละเอียดชิ้นส่วน ตรวจ Wireframe และ UV ตามขอบเขตงาน แล้วส่งภาพวัสดุให้ตรวจรอบสุดท้ายRefine the model, check topology and UVs where scoped, and share material previews for final review.

    4. ตรวจไฟล์และส่งมอบValidate and hand off

      ตรวจหน่วยและจุดหมุนของชิ้นส่วน แล้วส่งไฟล์ต้นฉบับ ไฟล์ Export และรายการไฟล์ตามที่ตกลงCheck units and part pivots, then deliver the agreed source files, exports, and a file inventory.

    ตัวอย่างเอกสารงาน 3DSample project documents

    ตัวอย่างจำลองสำหรับใช้คุยขอบเขตงานและตรวจการส่งมอบIllustrative templates for discussing scope, review, and delivery.

    บรีฟโมเดลเครื่องมือแพทย์Medical modeling brief ตัวอย่างบรีฟสำหรับโมเดลประกอบงานจำลองExample scope for a model used in a simulation.
    โจทย์Objective
    ขึ้นโมเดลแขนหุ่นยนต์จากภาพอ้างอิง ให้ฐาน ข้อต่อ และหัวจับเป็นวัตถุแยกModel a surgical robot arm from references, with the base, joints, and tool head as separate objects.
    ข้อมูลที่ต้องใช้Inputs
    ภาพหลายมุม ขนาดจริงอย่างน้อยหนึ่งจุด และข้อต่อที่ต้องตั้ง PivotMultiple reference views, at least one confirmed dimension, and the joints that need defined pivots.
    จุดตรวจรับReview criteria
    ตรวจสัดส่วน ชื่อชิ้นส่วน ตำแหน่ง Pivot และมุมสำคัญตามภาพอ้างอิงReview proportions, part names, pivot placement, and key views against the references.
    ขอบเขตตัวอย่างExample scope
    ขึ้นโมเดลและทำวัสดุสำหรับงานจำลอง โดยกำหนดการ Rig และการเชื่อมต่อเอนจินแยกตามบรีฟModeling and materials for simulation. Rigging and engine integration are scoped separately.
    ใบตรวจโมเดล Hard-SurfaceHard-surface review sheet ตัวอย่างรายการตรวจสำหรับชิ้นส่วนหรือชุดประกอบExample review criteria for a part or assembly.
    รูปทรงSilhouette
    เทียบด้านหน้า ด้านข้าง และมุมสามส่วน พร้อมภาพระยะใกล้จุดประกอบCompare front, side, and three-quarter views, with close-ups of assembly interfaces.
    โครงสร้างGeometry
    ตรวจรอยต่อ การซ้อนทะลุที่มองเห็น และรูปทรงหลังใช้ ModifierCheck seams, visible intersections, and the evaluated mesh after modifiers.
    วัสดุMaterials
    ตรวจความต่างของพื้นผิวและวัสดุในแสงกลาง พร้อมเช็ก UV และ Texture หากอยู่ในขอบเขตReview material separation under neutral lighting, and verify UVs and textures if scoped.
    ไฟล์ปลายทางExport
    เปิดไฟล์ Export กลับมาตรวจตำแหน่ง หน่วย และการแยกชิ้นส่วนอีกครั้งReopen the export to check orientation, units, and part separation.
    ตัวอย่างรายการไฟล์ส่งมอบSample handoff manifest ตัวอย่างโครงสร้างไฟล์สำหรับส่งต่อให้ทีมผลิตExample folder layout for production handoff.
    ไฟล์ต้นฉบับSource
    source/assembly.blend เก็บกลุ่มวัตถุ วัสดุ และชิ้นส่วนที่แก้ไขต่อได้source/assembly.blend contains organized objects, materials, and editable parts.
    ไฟล์ ExportExports
    exports/assembly.fbx หรือ .glb ตามที่ตกลงกับทีมปลายทางexports/assembly.fbx or .glb, depending on what the receiving team needs.
    ไฟล์ประกอบSupporting files
    textures/ และ previews/ รวมไฟล์วัสดุและภาพสำหรับตรวจเมื่ออยู่ในขอบเขตงานtextures/ and previews/ include material maps and reference renders where agreed.
    บันทึกการส่งมอบHandoff notes
    README ระบุเวอร์ชัน หน่วย แกน รูปแบบไฟล์ และรายการที่ทีมต้องตรวจหลังนำเข้าThe README records version, units, axes, formats, and the checks to make after import.
